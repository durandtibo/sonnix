# sonnix.modules

The modules are grouped by topic:

- [Activations](activation.md): Activation functions and element-wise math modules.
- [Losses](loss.md): Loss modules, the relative loss indicators and the shared base classes.
- [Numerical encoders](numerical.md): Modules that embed numerical features.
- [Fusion](fusion.md): Modules that merge several tensors into one.
- [Layers](layers.md): Linear layers, residual blocks, normalization-like layers and shape/dtype helpers.
