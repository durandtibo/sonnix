# Numerical encoders

Modules that embed numerical features. See also the [`sonnix.modules`](index.md) overview.

| Name                                                                                 | Description                                                                                                         |
| ------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------- |
| [`AsinhCosSinNumericalEncoder`](#sonnix.modules.AsinhCosSinNumericalEncoder)         | Extension of `CosSinNumericalEncoder` with an additional feature built using the inverse hyperbolic sine (arcsinh). |
| [`AsinhNumericalEncoder`](#sonnix.modules.AsinhNumericalEncoder)                     | Implement a numerical encoder using the inverse hyperbolic sine (asinh).                                            |
| [`CosSinNumericalEncoder`](#sonnix.modules.CosSinNumericalEncoder)                   | Implement a frequency/phase-shift numerical encoder where the periodic functions are cosine and sine.               |
| [`PiecewiseLinearNumericalEncoder`](#sonnix.modules.PiecewiseLinearNumericalEncoder) | Implement a numerical encoder using piecewise linear functions.                                                     |
