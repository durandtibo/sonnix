    validate_same_shape(
    tensor1: Tensor,
    tensor2: Tensor,
    *,
    name1: str = "tensor1",
    name2: str = "tensor2",
) -> None

    Validate that two tensors have the same shape.

    Parameters:

    Name Type Description Default
    tensor1 Tensor

    The first tensor to validate.

    		 required
    tensor2 Tensor

    The second tensor to validate.

    		 required
    name1 str

    The name of the first tensor, used in the error message.

    		 'tensor1'
    name2 str

    The name of the second tensor, used in the error message.

    		 'tensor2'

    Raises:

    Type Description
    TypeError

    If tensor1 or tensor2 is not a tensor.
    ValueError

    If the shapes of tensor1 and tensor2 differ.
    Example 
    >>> import torch
>>> from sonnix.validation import validate_same_shape
>>> validate_same_shape(torch.ones(2, 3), torch.zeros(2, 3))

    sonnix.validation.loss.validate_general_robust_params ¶

    validate_general_robust_params(
    alpha: float, scale: float, max_val: float | None
) -> None

    Validate the parameters of the general robust regression loss.

    Parameters:

    Name Type Description Default
    alpha float

    The shape parameter. It cannot be NaN or +inf (-inf is the Welsch limit).

    		 required
    scale float

    The scale parameter. It has to be strictly positive.

    		 required
    max_val float | None

    The max value to clip the loss, or None to disable the clipping. It has to be strictly positive.

    		 required

    Raises:

    Type Description
    ValueError

    if one of the parameters is invalid.
    Example 
    >>> from sonnix.validation import validate_general_robust_params
>>> validate_general_robust_params(alpha=1.0, scale=1.0, max_val=None)
