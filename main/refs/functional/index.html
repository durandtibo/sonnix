    safe_exp(
    input: Tensor,
    *,
    max_val: float = 20.0,
    preserve_gradient: bool = False,

    Compute safely the exponential of the elements.

    The values that are higher than the specified maximum value are set to this maximum value. Using a not too large positive value leads to an output tensor without Inf. A NaN input stays NaN.

    Note

    clamp has a zero gradient for the values outside of the range. Set preserve_gradient=True to keep the gradient of the unclamped input (straight-through estimator).

    Name Type Description Default
    input Tensor

    The input tensor.

    		 required
    max_val float

    		 20.0
    preserve_gradient bool

    If True, the gradient is computed as if the input was not clamped (straight-through).

    		 False

    Type Description

    safe_log(
    input: Tensor,
    *,
    min_val: float = 1e-08,
    preserve_gradient: bool = False,
) -> Tensor

    Compute safely the natural logarithm of the elements.

    The values that are lower than the specified minimum value are set to this minimum value. Using a small positive value leads to an output tensor without NaN or Inf. A NaN input stays NaN.

    Note

    clamp has a zero gradient for the values outside of the range. Set preserve_gradient=True to keep the gradient of the unclamped input (straight-through estimator).

    Note

    With preserve_gradient=True, the gradient is the one of the logarithm at the clamped value, 1 / min_val for an input lower than min_val (1e8 at 0 with the default min_val), not a finite or zero gradient.

    Parameters:

    Name Type Description Default
    input Tensor

    The input tensor.

    		 required
    min_val float

    The minimum value.

    		 1e-08
    preserve_gradient bool

    If True, the gradient is computed as if the input was not clamped (straight-through).

    		 False

    Returns:

    Type Description
    Tensor

    A tensor with the natural logarithm of the elements.

    Type Description

    sonnix.functional.poisson_regression_loss ¶

    poisson_regression_loss(
    prediction: Tensor,
    target: Tensor,
    *,
    eps: float = 1e-08,
    log_input: bool = False,
    reduction: Reduction = "mean",
) -> Tensor

    Compute the Poisson regression loss.

    Loss Functions and Metrics in Deep Learning https://arxiv.org/pdf/2307.02694

    Note

    This loss is similar to torch.nn.functional.poisson_nll_loss(log_input=False, full=False) with two differences: the predictions are clamped to eps (poisson_nll_loss adds eps instead), and there is no Stirling term. The predictions are clamped to eps in the whole loss, so the loss is bounded below and the gradient is zero for the predictions lower than eps.

    Note

    If log_input=True, the predictions are the logarithm of the rate, so they have no positivity constraint, and the loss is exp(prediction) - target * prediction (as torch.nn.functional.poisson_nll_loss(log_input=True) without the Stirling term). eps is not used.

    Parameters:

    Name Type Description Default
    prediction Tensor

    The count predictions. If log_input=False, the values must be positive: negative values are clamped to eps. If log_input=True, the values are the logarithm of the predicted rate.

    		 required
    target Tensor

    The count target values. The values must be non-negative (zero is allowed).

    		 required
    eps float

    An arbitrary small strictly positive number to avoid undefined results when the count is zero.

    		 1e-08
    log_input bool

    If True, the predictions are the logarithm of the rate.

    		 False
    reduction Reduction

    The reduction strategy: 'none', 'mean', 'sum' or 'batchmean'. See sonnix.functional.reduce_loss for the details.

    		 'mean'

    Returns:

    Type Description
    Tensor

    The Poisson regression loss. The shape of the tensor depends on the reduction strategy.

    prediction: Tensor,
    target: Tensor,

    eps: float = 1e-08,
    log_input: bool = False,

    Compute the Poisson regression loss.

    Loss Functions and Metrics in Deep Learning https://arxiv.org/pdf/2307.02694

    Note

    This loss is similar to torch.nn.functional.poisson_nll_loss(log_input=False, full=False) with two differences: the predictions are clamped to eps (poisson_nll_loss adds eps instead), and there is no Stirling term. The predictions are clamped to eps in the whole loss, so the loss is bounded below and the gradient is zero for the predictions lower than eps.

    Note

    If log_input=True, the predictions are the logarithm of the rate, so they have no positivity constraint, and the loss is exp(prediction) - target * prediction (as torch.nn.functional.poisson_nll_loss(log_input=True) without the Stirling term). eps is not used.

    		 required
